# Third-party notices

Every package/version/variant has independent disposition and license evidence
in `catalog/packages/`. Permitted Release archives retain upstream originals,
including original license and NOTICE files. Tool MIT terms do not extend to
those archives. Consult the selected version's evidence before using it.

Unity Companion/Reference-Only, Steam/native SDKs, Spine, PrimeTween and other
restricted or unresolved components are never granted permission by a wrapper
or registry label. Such records retain official acquisition/reference paths.

Upstream integrity is checked separately from SHA256 used for immutable vault
identity. A successful HTTP download is not a source/rights/adoption guarantee.
