## Required detail

Default selection remains bounded to three versions. Explicit four/five-version
exceptions retain earlier immutable records and named legacy/dependency lines;
the budget is enforced by seeds, selection, gap requests and fallback. Missing
versions are explicit, not replaced with latest neighbors. Fixed Git pins do not
enumerate tags; a monorepo archive is not certified as the Unity component.

23 official family rules carry API/type evidence. Unproved assemblies/full names,
SDK generations and component versions stay distinct. Family clues preserve
native eligibility and create sourcing work. Real observed missing package
versions and family clues survive identify → resolve → export, old-lock handling
and classifier cache binding. Tekly/OOI, modifications and shared business aliases
retain their earlier protections. See [classification](CLASSIFICATION.md).

Spine 4.2 observations distinguish Unity 4.2.120 from C# 4.2.37. The Unity manifest
still requests C# 4.2.0. FMOD source snapshots and SteamVR beta tags retain their
actual version basis. No combined SDK release or installed closure is invented.

Live2D retains the 2019 Unity/R11 and Unity/R12 labels and adds stable vendor tag
5-r.5 at c598e36eb2302a7e8a6177b2c8e52e9c1da21923, within three versions. That
line documents Cubism 5.3 compatibility, URP/custom passes and Input System
expectations; it does not support BIRP/HDRP. These statements do not certify an
Editor profile or native Core pairing. The older tags have no proved asmdef;
modern assembly bindings and renderer requirements are not transferred to them.

Monorepo archives keep complete original hashes, rights and file manifests.
Component routing separately indexes declarations whose actual file paths lie
inside sourcePath; sibling directories and external asmref sources retain native
eligibility. Compact indexes carry this scope; old summaries without path proof
remain weak. A whole-repository Git lock cannot certify an unnamed subcomponent.

## Diagnostic comparison and validation

against explicit baseline/current catalogs. Thirteen repositories include eight
diagnostic projects (two already inspected for evidence), five controls not used
for selection, and one unavailable metadata observation. Manifest and lock sources,
forks, Git/file specs, exact versions, acquisition and reference-only records remain
separate. Runtime consumers are unproved: complete-runtime ratios stay null.
Sample fractions are not market/game coverage or compilation/runtime success.

The suite reached 219 tests passing with one skipped. The installed wheel also
loaded all 23 family rules, 28 builtin rules, 111 active configuration entries
and the component module outside the checkout; its temporary environment was
removed. Frozen CLI and panel evidence bind their own explicit snapshots.
ReMaker adoption remains `integration-pending`: forward
[the original-writer handoff](REMAKER-WRITER-START-HERE.md); this repository does
not write the original project or run its games. Permitted payloads live remotely;
temporary acquisition/use directories are cleaned and no local mirror is kept.

## Actual collection

[Collector 39100901581](https://github.com/0everey/Unity-Package-Source-Vault/actions/runs/39100901581)
completed successfully: all 138 new archive tasks were acquired, bringing the
catalog to 234/235 completed tasks and 285 version/variant records. The only
remaining archive failure is the prior Burst 1.8.20 object above the 512 MiB
in-memory limit. It is not replaced by a nearby version.

Twenty published variant records represent 17 distinct original archive hashes
and nine package IDs. The five new permitted archives are Ink runtime 1.1.1 and
1.2.1, NavMeshComponents 2018.3.0f2 and 2019.4.0f1, and Yarn runtime 3.2.1.
Publication includes per-version rights and anonymous remote hash verification.
Other collected archives retain their own official-fetch-only or unresolved
rights; acquisition never upgrades redistribution permission.

SDK metadata records actual bundled DLL identities: for example Google Mobile
Ads has ten per selected archive, MAX seventeen and Facepunch twelve. Entries
with no decoded managed DLLs say so; a source wrapper is not a complete native
SDK. Sentry's prior independent component evidence remains unchanged.

Unrecognized vendor tag syntax is `vendor-tag-unassessed`, not automatically
prerelease. Live2D Unity/R12 retains independently observed official stable
release metadata, while R11 remains unassessed. SteamVR beta and modern Live2D
explicit statuses remain as evidenced. Eight new records were annotated without
changing original archives, licenses, fingerprints, SDK identities or old records.
