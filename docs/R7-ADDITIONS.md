## Required detail

Default selection remains bounded to three versions. Explicit four/five-version
exceptions retain earlier immutable records and named legacy/dependency lines;
the budget is enforced by seeds, selection, gap requests and fallback. Missing
versions are explicit, not replaced with latest neighbors. Fixed Git pins do not
enumerate tags; a monorepo archive is not certified as the Unity component.

23 official family rules carry API/type evidence. Unproved assemblies/full names,
SDK generations and component versions stay distinct. Family clues preserve
native eligibility and create sourcing work. Real observed missing package
versions and family clues survive identify → resolve → export, old-lock handling
and classifier cache binding. Tekly/OOI, modifications and shared business aliases
retain their earlier protections. See [classification](CLASSIFICATION.md).

Spine 4.2 observations distinguish Unity 4.2.120 from C# 4.2.37. The Unity manifest
still requests C# 4.2.0. FMOD source snapshots and SteamVR beta tags retain their
actual version basis. No combined SDK release or installed closure is invented.
